CP Coach

AI-powered competitive programming analytics platform

CP Coach is a full-stack web application that analyzes Codeforces profiles using real-time API integration and AI-powered insights. It evaluates user performance through contest history, rating progression, topic-wise strengths and weaknesses, success rate, and consistency score — and includes an AI-driven profile comparison module that compares two competitive programmers and generates intelligent summaries and study plans using Google's Gemini API.
